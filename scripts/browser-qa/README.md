# Executable browser baseline for planned Gemini 4 Argon tasks

This project-only workflow runs real headless Chromium through Playwright against a localhost Next.js preview and **synthetic read-only Medusa Store API fixture**. It covers exploratory ARG-B01–B05 foundations (Arabic RTL, English LTR, redirects, language switching, categories, search, interactive gallery, verified EGP region context, mobile viewport and keyboard skip link). GitHub Actions retains redacted QA screenshots and failure traces for seven days.

**This is not Gemini 4 Argon execution.** No connected Argon computer-use runner exists in this conversation. This CI baseline cannot claim human-like exploratory visual quality, an externally accessible preview, real Medusa 2.22.1 sales-channel authorization, actual goods/stock, payments, TP-01 execution or release readiness.

Run via GitHub Actions: Browser QA - Disposable Storefront (integration branch). No real customers, payments, inventory mutations, secrets, or deployment.
